# Underdog (Underdog Sports / Underdog Fantasy)

> Underdog is a Brooklyn, New York based sports gaming company founded in 2020 by Jeremy Levine. It operates daily fantasy sports, pick'em contests, and — since 2025 — federally regulated sports prediction markets, all on its own proprietary technology stack. Underdog does not publish a public developer API, developer portal, or machine-readable API contract; consumers reach the platform through its iOS, Android, and web applications.

## API status

- No public API: Underdog publishes no developer portal, no API documentation, no OpenAPI/Swagger, no GraphQL endpoint, no MCP server, and no A2A agent card. Every contract-discovery probe against underdogfantasy.com, underdogsports.com, api.underdogfantasy.com, stats.underdogfantasy.com, app.underdogsports.com and underdogpredict.com returned HTTP 404 or 403 on 2026-08-02.
- api.underdogfantasy.com is the non-public backend for the mobile and web applications. It is not documented, not versioned publicly, and carries no published terms of use for programmatic access.
- Third-party odds and player-prop feeds that advertise "Underdog APIs" are scrapers or aggregators operated by other companies, not first-party Underdog products.
- Note on name collision: docs.underdogprotocol.com and underdog.readme.io belong to Underdog Protocol, an unrelated Solana NFT infrastructure company.

## Products

- [Classic Pick'em](https://www.underdogsports.com/games/pickem): build a 2-to-5 pick entry on player statistical projections.
- [Pick'em Champions](https://www.underdogsports.com/games/pickem-champions): tournament-style pick'em format.
- [Draft Games](https://www.underdogsports.com/games/drafts): best-ball and season-long fantasy drafts.
- [Streaks](https://www.underdogsports.com/games/streaks): consecutive-pick contest format.
- [Team Picks](https://www.underdogsports.com/games/team-picks): team-outcome based picks.
- [Underdog Predict](https://underdogpredict.com/): CFTC-regulated sports prediction markets exchange.
- [Rules & Scoring](https://app.underdogsports.com/rules): the authoritative contest rules.
- [Average Results](https://www.underdogsports.com/average-results): published average customer outcomes.
